# 워크숍 모션 영상 의뢰 (심사2국 워크숍)

분임(7개)이 휴대폰으로 **AI 모션그래픽 광고제 분임 기획서**를 쓰고, 관리팀이 Claude로 만든 영상을 올리면 **각 분임 화면에서 바로 보는** Streamlit 앱입니다.
종이 기획서와 같은 칸, 같은 순서입니다(우리 분임 → 무엇을 만들까요 → 장면 구성 ①~④ → 발표 준비).
참가자는 노트북이 필요 없습니다. 관리팀 노트북 한 대만 있으면 됩니다.

## 화면 세 개 (주소 하나)

| 화면 | 주소 | 누가 |
|---|---|---|
| 분임 | `https://앱주소/` (분임 QR 카드로 바로 들어옴) | 분임 휴대폰 (분임 비밀번호) |
| 관리팀 | `https://앱주소/?view=admin` | 관리팀 노트북 (PIN) |
| 스크린 | `https://앱주소/?view=screen` | 프로젝터 (관리팀이 고른 영상을 크게 틀기 · 시사회 소개 화면 · 투표 QR · 결과 발표) |
| 투표 | `https://앱주소/?view=vote` | 각자 휴대폰 (스크린의 투표 QR로 들어옴 · 1인 1표) |

## 진행 순서

1. **분임**: QR 카드를 찍어 들어옵니다 → **처음 들어온 사람이 우리 분임 비밀번호(숫자 4자리)를 만듭니다** → 기획서를 씁니다(쓰는 대로 자동 저장) → [제출하기].
   다른 분임원은 같은 QR(또는 첫 화면에서 분임 고르기)로 들어와 그 비밀번호를 넣습니다.
   ★ 칸(주제·핵심 메시지·마지막 문구·영상 형식, 장면마다 화면에 보일 것·자막)을 채우고 **장면이 3개 이상**이어야 제출됩니다.
2. **관리팀**: [진행 현황]에서 분임을 고르고 [제작 시작] → **Claude에게 보낼 요청문**의 복사 버튼 → 새 Claude 대화창에 붙여 넣기(분임이 올린 캐릭터·로고 그림도 같이 첨부).
   요청문은 **제작 부스 프롬프트 틀**("너는 최고의 모션그래픽 디자이너야. ○○을 알리는 30초 모션그래픽 영상을 만들어줘." …)에 기획서 내용이 자동으로 채워진 글입니다.
3. Claude가 만든 mp4를 [결과물 올리기]로 올립니다. 분임 화면의 **[결과물]** 탭에 바로 뜹니다.
4. **분임**이 고칠 곳을 [수정 요청·문의]에 장면 번호로 적고(예: "③ 자막을 더 크게") **[✂ 수정 요청 보내기]** → 상태가 '수정 요청'으로 바뀝니다.
   수정 요청은 **분임마다 최대 2번**, 영상이 올라온 뒤에만 보낼 수 있습니다. 궁금한 점은 **[💬 문의 보내기]**(횟수 제한 없음, 상태 안 바뀜).
5. **관리팀**은 **수정 요청문**("전체를 다시 만들지 말고, 아래 부분만 고쳐줘…")을 복사해 그 영상을 만들었던 Claude 대화창에 이어서 보내고, 고친 영상을 다시 올립니다.
6. 발표 때는 **[🎞 시사회]** 탭에서 **[▶ 다음]**만 누르면 됩니다(아래 '시사회' 참고). 한 편만 바로 틀 때는 결과물 옆 [📺 스크린에 틀기].

## 시사회 (🎞 시사회 탭)

분임이 영상을 올리기만 하면 시사회 순서가 자동으로 채워집니다. 따로 슬라이드를 만들 필요가 없습니다.

1. 스크린 PC(프로젝터)에서 `https://앱주소/?view=screen`을 열고 **화면을 한 번 클릭**해 둡니다(소리 허용). 발표 자료를 넘기다가 시사회 차례가 되면 이 창으로 넘어옵니다.
2. 관리팀 노트북의 [🎞 시사회] 탭에서 **[▶ 다음]**을 누를 때마다 스크린이 이렇게 넘어갑니다.
   대기 판 → **1번째 분임 소개 화면** → 그 분임 **영상** → 2번째 분임 소개 화면 → … → **상영 끝 화면(투표 안내)** → 대기 판
3. **소개 화면**에는 기획서에 쓴 내용이 자동으로 나옵니다: 분임 이름, 영상 제목, 영상 형식, 감독·작가·프롬프트 담당·발표자, 발표 한마디(기획 의도·관전 포인트). 발표자가 이 화면을 보며 30초 소개를 합니다.
4. 영상은 그 분임이 **가장 최근에 올린 영상**이 나옵니다(수정본을 올리면 자동으로 수정본). 결과물이 없는 분임은 건너뜁니다.
5. 상영 순서는 기본이 1분임부터입니다. 바꾸려면 탭 아래 **상영 순서 바꾸기**에 `3,1,5`처럼 적고 [순서 저장](빠진 분임은 번호 순으로 뒤에 붙습니다).
6. 순서 목록의 **[🎤 소개] [▶ 영상]**으로 아무 분임이나 바로 띄울 수 있고, **[⏹ 대기 판으로] [🗳 투표 화면 (QR)]**도 있습니다.
7. 마지막 영상 뒤 [▶ 다음]을 누르면 스크린에 **투표 화면(QR)**이 뜨고 투표가 자동으로 열립니다.

## 투표 (🗳 투표 탭 · 1인 1표)

1. **행사 전에 명단 등록**: [🗳 투표] 탭 아래 **분임 명단 등록**에 분임마다 이름을 한 줄에 한 명씩 넣고 [명단 저장].
   분임이 없는 분(예: 국장님)은 **분임 없이 투표하는 사람** 칸에 넣으면 모든 작품에 투표할 수 있습니다.
   띄어쓰기는 무시하고 비교합니다. **같은 이름(동명이인)이 있으면 저장되지 않으니** `김민수A`, `김민수B`처럼 구분하고 본인에게도 그렇게 쓰라고 알려 주세요.
2. **투표 열기**: 시사회 탭에서 마지막 영상 뒤 [▶ 다음](또는 투표 탭의 [🗳 투표 열기 + 스크린에 QR]) → 스크린에 투표 QR과 참여 수가 나옵니다.
   분임 휴대폰 화면 위에도 "투표가 열렸어요" 안내가 뜹니다.
3. **각자 휴대폰**: QR → **내 이름** → 우리 분임 작품을 뺀 목록에서 한 편 → [투표하기]. 명단에 없는 이름, 이미 투표한 이름은 막힙니다.
   (이름으로만 확인하므로 남의 이름으로 먼저 투표하는 것까지는 막지 못합니다. "이미 투표한 이름"이라고 나오는 분이 있으면 관리팀이 확인해 주세요.)
4. 관리 화면에서 **참여 수·분임별 표**가 5초마다 새로 고쳐지고, **아직 투표하지 않은 사람**도 볼 수 있습니다. 누가 누구를 골랐는지는 보이지 않습니다.
5. **[⏹ 투표 마감]** → **[🏆 결과 발표 화면 띄우기]** → 누를 때마다 **3위 → 2위 → 1위** 순서로 공개됩니다(시상대 모양, 표가 같으면 공동 순위).
   상 이름은 [상 이름] 칸에서 바꿀 수 있습니다(기본: 최우수상, 우수상, 장려상).
6. 리허설 뒤에는 **[🧹 투표만 다시 하기]**(명단은 남음). [모두 지우고 처음부터]를 눌러도 표는 지워지고 명단은 남습니다.

## 리허설 (🧪 리허설 탭)

영상을 하나도 만들지 않고 **시사회 → 투표 → 결과 발표**를 처음부터 끝까지 연습합니다.

1. **[🧪 연습용 데이터 채우기]**(두 번 눌러 확인): 지금 데이터를 모두 지우고 7개 분임에 연습용 기획서(제목·감독·발표자·발표 한마디)와
   **샘플 영상**(`rehearsal_sample.mp4`, 7초, 카운트다운과 삐 소리 → 스크린 소리 확인용)을 넣고 '완성' 상태로 만듭니다. 설정은 남습니다.
   - **투표 명단도 연습 명단으로** 체크: `연습1-1`~`연습7-5`(분임마다 5명) + `연습국장`. 휴대폰으로 이 이름을 넣어 투표해 봅니다.
   - 체크를 끄면 이미 등록한 실제 명단으로 연습합니다.
2. [🎞 시사회] [▶ 다음] → 소개 화면 → 샘플 영상 → … → 투표 화면(QR) → 휴대폰으로 투표.
   사람이 적으면 **[🎲 연습용 표 채우기]**: 아직 투표 안 한 명단의 80%가 아무 작품에나 투표합니다(우리 분임 제외).
3. [🗳 투표] [⏹ 투표 마감] → [🏆 결과 발표]로 3위부터 공개.
4. 끝나면 **[🧹 리허설 끝: 모두 지우기]**. 연습 명단을 썼다면 명단도 지워지니 실제 명단을 등록하세요(실제 명단으로 연습했다면 명단은 남습니다).

리허설 데이터가 남아 있는 동안 관리 화면 맨 위에 경고가, 스크린 오른쪽 위에 **🧪 리허설** 표시가 나옵니다.
`rehearsal_sample.mp4`를 저장소에 올리지 않으면 영상 대신 분임 번호 그림이 들어갑니다(소리 확인은 안 됨).

상태: 작성 중 → 접수 완료 → 제작 중 → 완성 ⇄ 수정 요청. '제작 중'부터는 분임이 기획서를 못 고치고, 관리팀이 [↩ 분임이 다시 고치게]로 풀 수 있습니다.

## 배포 (Streamlit Community Cloud, 무료)

1. GitHub에 새 저장소를 만들고 **Add file → Upload files**로 5개를 올립니다: `app.py`, `store.py`, `requirements.txt`, `README.md`, `rehearsal_sample.mp4`
2. **Add file → Create new file**, 이름 칸에 `.streamlit/config.toml`을 그대로 쓰고, zip 안의 같은 파일 내용을 붙여 넣습니다.
   (화면 색과 **업로드 크기 300MB**가 들어 있습니다. 점으로 시작하는 폴더는 끌어다 놓기로 안 올라갑니다.)
3. share.streamlit.io → Create app → 저장소 선택, Main file `app.py`, Python 3.12
4. **Advanced settings → Secrets**에 **관리 화면 PIN** 한 줄을 넣습니다. 관리팀만 아는 숫자가 7391이라면:
   ```
   admin_pin = "7391"
   ```
   따옴표는 그대로 두고 숫자만 바꿉니다. **이 README에 적힌 예시 숫자를 그대로 쓰지 마세요**(GitHub에서 누구나 볼 수 있습니다).
   이 PIN은 관리 화면(`?view=admin`)에만 씁니다. 분임 비밀번호는 분임이 직접 만들므로 Secrets에 넣을 필요가 없습니다.
5. Deploy → 앱 주소를 관리 화면 [설정] 탭의 '앱 주소'에 넣고 저장 → **[분임 비밀번호·QR]** 탭에서 QR 카드를 내려받아 인쇄합니다.
6. 앱 Share 설정이 **공개(public)** 인지 확인합니다(로그인 없이 휴대폰으로 열리도록).

## 행사 전 준비

- [설정]: 행사 이름, 분임 이름 7개, 분임 화면 안내 문구(예: 제출 마감 시각)
- QR 카드 인쇄(A4 한 장에 2분임) → 분임마다 나눠 주기
- [🗳 투표] 탭에서 분임 명단 등록(동명이인은 구분), 상 이름 확인
- **[🧪 리허설]** 탭으로 시사회·투표·결과 발표를 한 번 돌려 보고 **[리허설 끝: 모두 지우기]** (위 '리허설' 참고)
- 휴대폰 한 대로 기획서 제출 → 결과물 올리기 → 수정 요청도 한 번 해 보고, 다시 **모두 지우기**(리허설로 만든 분임 비밀번호도 같이 지워집니다)
- 분임 화면 첫 안내는 "★ 칸만 채우면 돼요. 20분 안에 쓰고 맨 아래 [제출하기]를 눌러 주세요."입니다. [설정]에서 바꿀 수 있습니다.
- 영상은 한 편씩 만들어서 시간이 걸립니다(30초 영상도 수정까지 20~40분 정도). 관리팀이 Claude 대화창을 여러 개 열어 나눠 만들면 빨라집니다.

## 분임 비밀번호

- 분임에서 **처음 들어온 사람**이 만듭니다(숫자 4자리). 관리팀도 숫자는 볼 수 없고, 서버에는 알아볼 수 없는 형태로만 저장됩니다.
- 잊었거나 다른 분임이 잘못 만들었으면: 관리 화면 **[분임 비밀번호·QR]** → 그 분임 **[🔄 초기화]** → 분임이 다음에 들어올 때 새로 만듭니다.
  이미 들어와 있던 휴대폰도 나가지니, 새 비밀번호를 분임원에게 다시 알려 주세요. 기획서·결과물은 그대로 남습니다.
- 5번 연속 틀리면 30초 동안 막힙니다.
- 무료 서버가 다시 켜져 데이터가 지워지면 비밀번호도 지워집니다. [백업·초기화]의 백업 파일로 되살리면 비밀번호도 같이 돌아옵니다.

## 주의

- **무료 서버는 다시 켜지면 저장된 내용이 지워질 수 있습니다.** [백업·초기화]에서 중간중간 백업 파일을 받고, 완성 영상 원본은 관리팀 노트북에도 보관하세요.
  끝나면 [📦 모든 결과물 묶음]으로 한꺼번에 내려받을 수 있습니다.
- 한동안 아무도 안 쓰면 앱이 잠듭니다. 행사 30분 전에 한 번 열어 깨워 두세요. 행사 중에는 GitHub 파일을 고치지 마세요(앱이 다시 켜짐).
- 외부 서버입니다. 기획서·첨부에 **내부자료(업무 문서·보고서)를 넣지 않도록** 분임 화면에 안내가 나옵니다.
- 영상에는 새로 만든 음악·그림만 씁니다(기존 노래·유명 캐릭터·남의 로고 X, 욱일기처럼 보이는 햇살 무늬 X). 요청문에 자동으로 들어갑니다.
