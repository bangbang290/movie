# 워크숍 모션 영상 의뢰 (심사2국 워크숍)

분임(7개)이 휴대폰으로 **영상 의뢰서**를 쓰고, 관리팀이 Claude로 만든 영상을 올리면 **각 분임 화면에서 바로 보는** Streamlit 앱입니다.
참가자는 노트북이 필요 없습니다. 관리팀 노트북 한 대만 있으면 됩니다.

## 화면 세 개 (주소 하나)

| 화면 | 주소 | 누가 |
|---|---|---|
| 분임 | `https://앱주소/` (분임 QR 카드로 바로 들어옴) | 분임 대표 휴대폰 |
| 관리팀 | `https://앱주소/?view=admin` | 관리팀 노트북 (PIN) |
| 스크린 | `https://앱주소/?view=screen` | 프로젝터 (관리팀이 고른 영상을 크게 틀기) |

## 진행 순서

1. **분임**: QR 카드를 찍어 들어옵니다 → 의뢰서를 씁니다(쓰는 대로 자동 저장) → [제출하기].
2. **관리팀**: [진행 현황]에서 분임을 고르고 [제작 시작] → **Claude에게 보낼 요청문**의 복사 버튼 → 새 Claude 대화창에 붙여 넣기(분임이 올린 자료도 같이 첨부).
3. Claude가 만든 mp4를 [결과물 올리기]로 올립니다. 분임 화면의 **[결과물]** 탭에 바로 뜹니다.
4. **분임**이 고칠 곳을 [수정 요청·문의]에 장면 번호로 남기면 상태가 '수정 요청'으로 바뀝니다.
5. **관리팀**은 **수정 요청문**을 복사해 그 영상을 만들었던 Claude 대화창에 이어서 보내고, 고친 영상을 다시 올립니다.
6. 발표 때는 결과물 옆 [📺 스크린에 틀기] → 스크린 화면에서 자동 재생됩니다(스크린 화면을 처음에 한 번 클릭해 두세요).

상태: 작성 중 → 접수 완료 → 제작 중 → 완성 ⇄ 수정 요청. '제작 중'부터는 분임이 의뢰서를 못 고치고, 관리팀이 [↩ 분임이 다시 고치게]로 풀 수 있습니다.

## 배포 (Streamlit Community Cloud, 무료)

1. GitHub에 새 저장소를 만들고 **Add file → Upload files**로 4개를 올립니다: `app.py`, `store.py`, `requirements.txt`, `README.md`
2. **Add file → Create new file**, 이름 칸에 `.streamlit/config.toml`을 그대로 쓰고, zip 안의 같은 파일 내용을 붙여 넣습니다.
   (화면 색과 **업로드 크기 300MB**가 들어 있습니다. 점으로 시작하는 폴더는 끌어다 놓기로 안 올라갑니다.)
3. share.streamlit.io → Create app → 저장소 선택, Main file `app.py`, Python 3.12
4. **Advanced settings → Secrets**에 한 줄:
   ```
   admin_pin = "관리팀 PIN 숫자"
   ```
   분임 코드도 이 값으로 계산됩니다. 그래서 행사 중에 PIN을 바꾸면 분임 코드도 바뀝니다(바꾸지 마세요).
5. Deploy → 앱 주소를 관리 화면 [설정] 탭의 '앱 주소'에 넣고 저장 → [분임 코드·QR] 탭에서 QR 카드를 내려받아 인쇄합니다.
6. 앱 Share 설정이 **공개(public)** 인지 확인합니다(로그인 없이 휴대폰으로 열리도록).

## 행사 전 준비

- [설정]: 행사 이름, 분임 이름 7개, 분임 화면 안내 문구(예: 제출 마감 시각)
- QR 카드 인쇄(A4 한 장에 2분임) → 분임마다 나눠 주기
- 한 분임으로 의뢰서 제출 → 결과물 올리기 → 수정 요청까지 한 번 해 보고, [백업·초기화]에서 **모두 지우고 처음부터**
- 의뢰서는 **가능하면 전날까지** 받아 두세요. 영상은 한 편씩 만들어서 시간이 걸립니다(짧은 영상도 수정까지 20~40분 정도).
  길이는 15~30초로 정하고, 관리팀이 Claude 대화창을 여러 개 열어 나눠 만들면 빨라집니다.

## 주의

- **무료 서버는 다시 켜지면 저장된 내용이 지워질 수 있습니다.** [백업·초기화]에서 중간중간 백업 파일을 받고, 완성 영상 원본은 관리팀 노트북에도 보관하세요.
  끝나면 [📦 모든 결과물 묶음]으로 한꺼번에 내려받을 수 있습니다.
- 한동안 아무도 안 쓰면 앱이 잠듭니다. 행사 30분 전에 한 번 열어 깨워 두세요. 행사 중에는 GitHub 파일을 고치지 마세요(앱이 다시 켜짐).
- 외부 서버입니다. 의뢰서·첨부에 **내부자료(업무 문서·보고서)를 넣지 않도록** 분임 화면에 안내가 나옵니다.
- 영상에는 새로 만든 음악·그림만 씁니다(기존 노래·유명 캐릭터·남의 로고 X, 욱일기처럼 보이는 햇살 무늬 X). 요청문에 자동으로 들어갑니다.

## 파일

- `app.py` 화면(분임·관리팀·스크린) · `store.py` 저장(의뢰서·첨부·결과물·대화, SQLite + 파일 폴더) · `.streamlit/config.toml` 색·업로드 크기
